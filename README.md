## Hardware and installation

1. Open DisplayClientV2/DisplayClientV2.ino.
2. Select Mega 2560 / ATmega2560 or Uno r3. Install Seeed's CAN_BUS_Shield library providing mcp2515_can.h.
3. Upload the sketch. In SimHub select this Mega in Multiple USB mode, enable Arduino Custom Protocol and Use JavaScript, and paste SimHubFormula_LexusRC350.js.

## Turn Indicator Wiring relay
D4- left, D5 - right, D6 - hazard;
